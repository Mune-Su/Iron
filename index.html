Copilot link setup (one time)

Needs: a Microsoft 365 Copilot licence on your work account, plus an app registration your IT admin consents to.

1. Run Iron from localhost or your hosted https address (sign-in doesn't work from a double-clicked file). For localhost, in the folder with the HTML:
npx serve -l 5500 → open http://localhost:5500.
2. Entra admin centre → App registrations → New registration → platform Single-page application, redirect URI = the value above.
3. API permissions → Microsoft Graph → Delegated: Sites.Read.All, Mail.Read, People.Read.All, OnlineMeetingTranscript.Read.All, Chat.Read, ChannelMessage.Read.All, ExternalItem.Read.All → Grant admin consent.
4. Paste the tenant + client IDs here, Save, then Sign in.

Heads up: this is Copilot's beta Chat API. Copilot keeps the chat history on its side and answers grounded in your work data. Model picking, temperature and reply length don't apply. Check your company's IT policy before using a work account for personal projects.

Tuning

Free keys (one time, no card needed)

Gemini: aistudio.google.com → Get API key. Best free option for coding.
Mistral: console.mistral.ai → pick the Free plan → API Keys. Use codestral-latest for code.
Groq: console.groq.com → API Keys.
OpenRouter: openrouter.ai → Keys. Fetch list only shows the free models.
Then paste the key, hit Fetch list, pick a model, Save.

Free tiers have daily limits, and some providers may use free-tier prompts to improve their models, so don't paste work secrets into them. Use Ollama when you need fully private.

Ollama setup (one time)

1. winget install Ollama.Ollama
2. ollama pull llama3.1
3. [Environment]::SetEnvironmentVariable("OLLAMA_ORIGINS","*","User") then restart Ollama

Identity

Live avatar

Her actual portrait, brought to life: she blinks, breathes, leans toward your mouse/finger, glows while thinking and moves her lips when she talks. Tap her for a nod. On PC, hover the dock → ⧉ pops her out into a small always-on-top window (Edge/Chrome).

Personality / system prompt

{name} and {user} are swapped in automatically.

Iron's voice

Uses the voices built into your device. On Android: Settings → Text-to-speech → Google, English (Australia) for an Aussie accent.

Talk to her

Tap 🎤, speak, and she types it for you. Needs Chrome or Edge, and mic permission the first time.

Quick action buttons

One per line: Label | prompt text. Shown on the new-chat screen.

Backup

API key is never included in backups. Use this to move your chats from PC to phone.
